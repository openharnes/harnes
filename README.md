# OpenHarnes

**Harnes is the open coding agent.**

## Install

```bash
npm install -g @openharnes/harnes
# or
curl -fsSL https://openharnes.com/install | bash
harnes
```

`harnes` opens a persistent session. First run walks you through OpenRouter or Ollama setup.

## One-shot

```bash
export OPENROUTER_API_KEY=sk-or-...
harnes run "explain this repo"
```
