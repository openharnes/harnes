How it works

No vendor lock-in. Bring the model, harnes brings the runtime.

  • [1] Install harnes npm or curl — MIT licensed
  • [2] Set OPENROUTER_API_KEY or point at a local Ollama endpoint
  • [3] Open a session harnes — agent reads, edits, and runs with permission checks
  • [4] Pick models live OpenRouter catalog in /models, pin with /model
